# make-a-wish 许愿池

A quiet top-down wishing pond in the browser. Tap the water to make ripples and scare the koi, hold and flick upward to toss a coin, and land it in the stone bowl to write a wish that floats away as a lantern.

- Play: https://jacey-dai.github.io/make-a-wish/ (GitHub Pages, updates when `main` changes)
- Run locally: open `index.html` in a browser. No build, no dependencies.
- Requirements and task board: [`docs/PRD.md`](docs/PRD.md)
- Working on it as an agent: read [`AGENTS.md`](AGENTS.md) first.

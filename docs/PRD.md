## 概述

许愿池是一个在浏览器里玩的俯视水池互动小作品：触摸水面会荡开涟漪、惊走锦鲤，把铜钱投进池中的许愿区就能写下一个愿望，愿望化成河灯飘走。目标是一个打开就想点、点了会心一笑的安静画面。

**目标**

- 桌面和手机浏览器都能流畅玩（60fps，支持触屏）
- 三秒内看懂怎么玩，不需要教程
- 许愿有仪式感：投中、写愿、放灯是一条完整的小故事
- 结构清楚，多个 agent 可以分头做功能而不互相覆盖

**非目标（本阶段不做）**：账号、登录、付费；原生 App；3D 引擎。

**体验原则**

- 安静优先：动画和声音都要轻，没有弹窗和打断
- 每个操作都要有水的反馈（涟漪、水花、鱼的反应）
- 东方细节：方孔铜钱、睡莲、河灯、签文

## 美术方向

v0.5 起按 Jacey 第二组参考图（4 张遗迹、睡莲池、清澈溪水的图和 1 张涟漪图）调整，取代 v0.4 的白凉亭、石板小路和灯串。一句话：**阳光照进长满青苔的石头遗迹，清澈的翡翠水里浮着睡莲和小白花**。像吉卜力式的手绘背景，唯美、安静，一眼看得出是游戏。

- **视角和纵深**：斜俯视（约 3/4 视角）。远处是爬满藤蔓、长着青苔的灰绿石墙，正中一道拱门，拱门里透出明亮的林间光，一道小瀑布从拱门流下青苔石阶落进池子；两侧草地上立着断掉的石柱；近处角落是岩石和蕨类。
- **色彩**：受光处是嫩绿、黄绿（树叶、睡莲叶、苔藓），阴影是深绿；石头是带绿调的灰；水是清澈的翡翠绿，近处浅、远处深。点缀色只有白色（睡莲花、小白花）和一点暖黄（花心、阳光）。不用纯黑、冷灰和粉色系。
- **水**：清澈见底，能看到水底长苔的圆石；水面有流动的焦散光纹、林间光斑、一闪一闪的高光；成片的睡莲叶聚成几簇，夹着白色睡莲；水面漂着小小的五瓣白花，会被涟漪推开。
- **涟漪**：要通透，像真水一样：多圈细细的同心圆，每圈是一道亮边加一道暗边，底下的东西会被轻微折射错位，亮边上有几个小高光点；不能是一圈不透明的白线。
- **光**：阳光从左上方斜射进来，柔和的黄绿色光束，空中飘着细小的光点。
- **池边**：不规则的青苔圆石围一圈，夹着草和小白花，不用规整的石沿或石板路。
- **新元素要求**：新加的东西（落叶、金锦鲤、昼夜等）必须用这套配色和光线；画在水里的东西走水面图层（会被斜视压扁），画在岸上、水面上和空中的东西走屏幕图层并用 `toScreen()` 转坐标。

## 功能详情与验收标准

### F0 交互重构：点击触水，按住上甩投币

轻点水面 = 用手指碰水：荡开涟漪，附近的锦鲤受惊游开。按住并往上甩 = 投币，甩的方向和速度决定落点。按住后不甩直接松手，铜钱不会投出，并提示“往上甩一下”。鼠标和触屏行为一致。

- [x] 点击水面产生涟漪，不投币
- [x] 半径约 150px 内的锦鲤立即加速远离点击点，2–3 秒后恢复闲游
- [x] 甩动手势在鼠标和触屏上都能投币，甩得越快飞得越远（真机触屏待 Jacey 验证）
- [x] 按住时有一枚铜钱跟着手指，甩动时显示预估落点
- [x] 空格键仍可随机投币（无障碍）

### F1 许愿区与投中判定

池心水底有一个刻着“愿”字的石碗。铜钱落点在碗内算“投中”，可以许愿；没投中只是普通落水，靠近时提示“差一点”。

- [x] 许愿区在桌面和手机上都清晰可见，大小随池子缩放
- [x] 投中有明显反馈：大片金光、“投中了”字样、铜钱沉入碗中
- [x] 没投中的反馈温和，不让人沮丧
- [x] 计数分两项：投币数和投中数

### F2 写愿望，化作河灯飘走

投中后底部浮出一个输入框“投中了，写下你的愿望”。确认后愿望变成一盏莲花河灯，从石碗慢慢漂向池边。

- [x] 输入框不遮挡池子主体，可以跳过（“先不写”或 Esc）
- [x] 愿望最长 40 字，空愿望不发灯
- [x] 河灯有烛光闪烁、水面光晕和尾迹涟漪，约 20 秒后淡出
- [x] 鼠标悬停或点击河灯显示愿望全文
- [x] 最近 20 个愿望存在本地，刷新后可在“我的愿望”里看到

### F3 落叶飘落

- [ ] 每 8–20 秒一片叶子从画面外飘落，左右摇摆、旋转
- [ ] 落在水上时有小涟漪，然后随水漂流并淡出；落在石头上就停住
- [ ] 同屏最多 6 片，叶子颜色可配合季节或昼夜

### F4 稀有金锦鲤与抽签

- [ ] 每次投币有约 5% 概率招来一条发光的金锦鲤
- [ ] 金锦鲤吃到铜钱后弹出一张签（上上签 / 上签 / 中签，不出下签），配一句签文
- [ ] 签文至少 30 条，原创内容

### F5 昼夜变化

- [ ] 按用户本地时间分晨、日、黄昏、夜四档配色，切换时渐变
- [ ] 夜间有萤火虫，河灯更亮
- [ ] 提供一个手动切换入口方便预览

v0.3 起所有音效已按 Jacey 的要求删除（v0.1/v0.2 的合成音效太难听）。重新加声音时由本功能统一负责，音色先给 Jacey 试听确认。

- [ ] 默认关闭，由用户点击开启

## 技术约定

保持单个 HTML 文件、零依赖，直到 F8 需要后端时再拆。任何平台的 agent 都能直接打开、修改、预览。

- **文件**：`index.html`。样式在 `<style>`，逻辑在一个立即执行函数里，按注释分区：`geometry` / `scenery` / `koi` / `coins` / `F0 touch water` / `F2 wishes and lanterns` / `sound` / `layout` / `draw` / `F0 input`。新功能新开一个分区，注释写功能 ID。
- **渲染**：Canvas 2D，斜俯视。静态场景在 `layout()` 时画进三张离屏画布：`bgC`（树林、青苔石墙和拱门、断柱、草地、石阶、池壁）、`rimC`（池边青苔石、草和小花）、`fgC`（角落岩石、暗角）。`frame()` 每帧顺序固定：`bgC` →（水面图层，裁切到水面）水体和水底石、石碗、沉币、鱼影、锦鲤、水色、焦散光纹和光斑、微光、睡莲、河灯 →（屏幕图层）涟漪（含折射）、漂浮小白花、波光、`rimC`、瀑布、`fgC`、河灯文字、手中铜钱、飞行中的铜钱、水花、浮字、光束和光点。新物体先想好它在哪一层。
- **坐标**：游戏逻辑全部用“世界坐标”（CSS 像素，俯视）。池子是椭圆 `pond {cx, cy, rx, ry}`，许愿区是 `bowl {x, y, R}`。水面图层在绘制时纵向压缩 `view.T` 形成斜视，世界坐标转屏幕坐标用 `toScreen(x, y)`，屏幕 y 转世界用 `toWorldY(y)`；指针位置已经转成世界坐标。尺寸乘以缩放系数 `S`（场景装饰用 `view.sc`），判断是否在水里用 `inWater(x, y, pad)`。窗口变化时 `layout()` 会把物体重新映射并重画场景，新加的持久物体也要加进去。
- **性能**：中端手机上 60fps。每帧不新建大量对象，粒子设上限，不用 `ctx.filter`。
- **输入**：统一用 Pointer Events，鼠标和触屏同一套代码。画布 `touch-action: none`。
- **存储**：`store.get/set`，键名自动加前缀 `wishpond.`。现有键：`count`、`hits`、`wishes`。
- **声音**：目前没有任何声音。不要私自加音效，声音统一走 F6。
- **文案**：界面文字用中文，代码和注释用英文。
- **预览**：直接用浏览器打开 `index.html`。也会发布为 Claude Artifact：[许愿池](https://claude.ai/artifact/KcuPEhtfwvDUy2fGKCgbFS)。

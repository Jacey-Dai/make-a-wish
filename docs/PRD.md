## 概述

许愿池是一个在浏览器里玩的俯视水池互动小作品：触摸水面会荡开涟漪、惊走锦鲤，把铜钱投进池中的许愿区就能写下一个愿望，愿望化成河灯飘走。目标是一个打开就想点、点了会心一笑的安静画面。

**目标**

- 桌面和手机浏览器都能流畅玩（60fps，支持触屏）
- 三秒内看懂怎么玩，不需要教程
- 许愿有仪式感：投中、写愿、放灯是一条完整的小故事
- 结构清楚，多个 agent 可以分头做功能而不互相覆盖

**非目标（本阶段不做）**：账号、登录、付费；原生 App；3D 引擎。

**体验原则**

- 安静优先：动画和声音都要轻，没有弹窗和打断
- 每个操作都要有水的反馈（涟漪、水花、鱼的反应）
- 东方细节：方孔铜钱、睡莲、河灯、签文

## 美术方向

v0.5 起按 Jacey 第二组参考图（4 张遗迹、睡莲池、清澈溪水的图和 1 张涟漪图）调整，取代 v0.4 的白凉亭、石板小路和灯串。一句话：**阳光照进长满青苔的石头遗迹，清澈的翡翠水里浮着睡莲和小白花**。

v0.6 起 Jacey 要求**写实、唯美、有立体感，不要卡通**（取代之前“手绘、一眼看得出是游戏”的说法）。具体做法：远景和近景虚化（景深），远处加一层空气感的薄雾和光斑；石头、睡莲叶、锦鲤都要有受光面、背光面和投影；整体加一点胶片颗粒；不用平涂色块和描边。

v0.7 起场景改为**藏在森林深处的许愿池**（Jacey 2026-10-30：水波和池子本身保持不变，其余要有纵深）。v0.8 起背景做成**立体的多层景深**：远中近几层森林会随镜头轻微移动而错开（视差），石墙、拱门和断柱按屏幕宽窄放回场景。

- **视角和纵深**：斜俯视（约 3/4 视角）。远景是三层朦胧的森林，越远越淡、越虚，林间有薄雾和斜射的光柱；偶尔有一只小鹿从林边走出来，低头吃草，再走回去。更近处有几棵粗大的树干框住画面。林间立着几根断柱（宽屏多、竖屏少），宽屏时池边空地上还各有一根。中景是一段爬满藤蔓的残破石墙，正中一道透着林光的拱门立在青苔岩堆上，小瀑布从拱门流出、顺着岩石落进池子，水流有向下流动的水纹，落水处有水沫和升起的水雾。池子周围是森林地面（苔藓、草、落叶）和零散的青苔石。近景两角堆着青苔石块和蕨类，虚化、偏暗。手机竖屏时瀑布变短，岩堆贴近池子。
- **色彩**：受光处是嫩绿、黄绿（树叶、睡莲叶、苔藓），阴影是深绿；石头是带绿调的灰；水是清澈的翡翠绿，近处浅、远处深。点缀色只有白色（莲花、小白花）、莲花尖上的淡粉和一点暖黄（花心、阳光）。远处的东西混进淡黄绿的雾色。不用纯黑和冷灰。
- **水**：清澈见底，能看清水底的沙、卵石、苔石、落叶和水草，越往池心越深、颜色越偏翡翠绿；水底有随水面变化的焦散光网和树荫光斑；水面倒映远处的森林和岩堆（远处倒影强、近处几乎透明）；阳光在波面上闪出高光。成片的睡莲叶聚成几簇：叶子有厚度（能看到侧边），有叶脉纹理和蜡质反光，叶面上有水珠，周围水面有一圈暗影；莲花是立体的三层花瓣，白色带粉色花尖，中间是黄色莲蓬，水面上有倒影；水面漂着小小的五瓣白花，会被涟漪推开。睡莲叶和小白花在水底留下影子，会随波起伏。
- **河灯**（F2）：写完愿望放出的是一盏白色纸莲花灯，三层立体花瓣从里面透出暖黄烛光，托在一片莲叶上，水面有拉长的暖色倒影和一圈光晕。约 20 秒后淡出。
- **涟漪**：必须是真实的水波，不是画上去的圈：水面高度场模拟，波纹会扩散、反弹、互相干涉，经过的地方把水底和锦鲤折射错位，并在水底聚出移动的焦散亮环；投币会连续弹起几下，留下一串同心波。锦鲤快游时拖出尾迹，偶尔有小虫点水。
- **光**：阳光从左上方斜射进来，柔和的黄绿色光束，空中飘着细小的光点。
- **池边**：不规则的青苔圆石围一圈，夹着草和小白花，不用规整的石沿或石板路。
- **新元素要求**：新加的东西（落叶、金锦鲤、昼夜等）必须用这套配色和光线；画在水里的东西走水面图层（会被斜视压扁），画在岸上、水面上和空中的东西走屏幕图层并用 `toScreen()` 转坐标。

## 功能详情与验收标准

### F0 交互重构：点击触水，按住上甩投币

轻点水面 = 用手指碰水：荡开涟漪，附近的锦鲤受惊游开。按住并往上甩 = 投币，甩的方向和速度决定落点。按住后不甩直接松手，铜钱不会投出，并提示“往上甩一下”。鼠标和触屏行为一致。

- [x] 点击水面产生涟漪，不投币
- [x] 半径约 150px 内的锦鲤立即加速远离点击点，2–3 秒后恢复闲游
- [x] 甩动手势在鼠标和触屏上都能投币，甩得越快飞得越远（真机触屏待 Jacey 验证）
- [x] 按住时有一枚铜钱跟着手指，甩动时显示预估落点
- [x] 空格键仍可随机投币（无障碍）

### F1 许愿区与投中判定

池心水底有一个刻着“愿”字的石碗。铜钱落点在碗内算“投中”，可以许愿；没投中只是普通落水，靠近时提示“差一点”。

- [x] 许愿区在桌面和手机上都清晰可见，大小随池子缩放
- [x] 投中有明显反馈：大片金光、“投中了”字样、铜钱沉入碗中
- [x] 没投中的反馈温和，不让人沮丧
- [x] 计数分两项：投币数和投中数

### F2 写愿望，化作河灯飘走

投中后底部浮出一个输入框“投中了，写下你的愿望”。确认后愿望变成一盏莲花河灯，从石碗慢慢漂向池边。

- [x] 输入框不遮挡池子主体，可以跳过（“先不写”或 Esc）
- [x] 愿望最长 40 字，空愿望不发灯
- [x] 河灯有烛光闪烁、水面光晕和尾迹涟漪，约 20 秒后淡出
- [x] 鼠标悬停或点击河灯显示愿望全文
- [x] 最近 20 个愿望存在本地，刷新后可在“我的愿望”里看到

## 技术约定

保持单个 HTML 文件、零依赖，直到 F8 需要后端时再拆。任何平台的 agent 都能直接打开、修改、预览。

- **文件**：`index.html`。样式在 `<style>`，逻辑在一个立即执行函数里，按注释分区：`geometry` / `scenery` / `koi` / `coins` / `F0 touch water` / `F2 wishes and lanterns` / `layout` / `draw` / `water surface (WebGL)` / `F0 input`。新功能新开一个分区，注释写功能 ID。
- **渲染**：斜俯视，三层画布叠在一起。静态场景在 `layout()` 时画进三张离屏画布：`bgC`（三层朦胧森林、光柱、森林地面、青苔岩堆、池壁，远处已做景深虚化）、`rimC`（池边青苔石、草和小花）、`fgC`（角落青苔石堆和蕨类，已虚化；暗角；胶片颗粒）。
  - **水面（WebGL，v0.6 起）**：`setupWater()` 在 `layout()` 里建好水底画布 `water.floorC`、波动网格和倒影贴图。每帧 `renderWater()` 先把“水下的东西”画进 `water.underC`（水底、石碗、沉币、睡莲和花的影子、鱼影、锦鲤），再推进波动模拟，最后由片元着色器做折射、焦散、吸收、倒影和高光。WebGL 画布 `gcv` 和静态背景 `bgEl` 是 `#pond` 下面的两层 DOM 画布，`#pond` 只画水面以上的东西。
  - **水下的东西**要画进 `renderWater()` 里那一段（这时全局 `ctx` 临时指向 `water.underC`，坐标仍是世界坐标），这样才会被折射。**浮在水面的东西**画在 `frame()` 的水面图层（睡莲、河灯、光晕），用 `waveAt(x, y)` 让它随波起伏。
  - **涟漪**一律调用 `addRipple({x, y, max, a, big, delay})`，不要直接往 `ripples` 里塞：有 WebGL 时会变成真实的波，没有时退回画圈。底层是 `waveDrop(x, y, 半径, 强度)`。
  - **退回**：浏览器不支持 WebGL（或网址带 `?flat`）时走 2D 画法，`frame()` 里 `else` 分支保持 v0.5 的顺序。改水面效果时两条路都要能跑。
  - **景深层（v0.8）**：`paintBackground()` 把背景拆成 `layers`：三层树林（含天空、断柱）、近处大树干和光柱、静止的空地层（地面、石墙拱门、岩堆、池壁）。有 WebGL 时每层是一张 DOM 画布，`updateCam()` 按 `depth` 给它们加横向位移；镜头由缓慢摆动、桌面鼠标位置、手机倾斜（`deviceorientation`）驱动。近景 `fgC` 和小鹿也跟着移。`bgC` 是所有层的平面合成，2D 退回和水面倒影用它。池子和水不动，所以点击坐标不受影响。
  - `frame()` 每帧顺序：（WebGL）清空 `#pond` → `renderWater()` → 水面图层：光晕、睡莲叶、河灯 → 漂浮小白花 → 莲花（屏幕坐标，立体花瓣）→（两条路共用）小鹿 `drawDeer()`、`rimC`、瀑布、`fgC`、河灯文字、手中铜钱、飞行中的铜钱、水花、浮字、光束和光点。新物体先想好它在哪一层。
- **坐标**：游戏逻辑全部用“世界坐标”（CSS 像素，俯视）。池子是椭圆 `pond {cx, cy, rx, ry}`，许愿区是 `bowl {x, y, R}`。水面图层在绘制时纵向压缩 `view.T` 形成斜视，世界坐标转屏幕坐标用 `toScreen(x, y)`，屏幕 y 转世界用 `toWorldY(y)`；指针位置已经转成世界坐标。尺寸乘以缩放系数 `S`（场景装饰用 `view.sc`），判断是否在水里用 `inWater(x, y, pad)`。窗口变化时 `layout()` 会把物体重新映射并重画场景，新加的持久物体也要加进去。
- **性能**：中端手机上 60fps。每帧不新建大量对象，粒子设上限。`ctx.filter`（模糊）只在 `layout()` 画静态画布时用，每帧不用。水底画布最高 1.5 倍像素密度，波动网格最多约 170 格宽。
- **输入**：统一用 Pointer Events，鼠标和触屏同一套代码。画布 `touch-action: none`。
- **存储**：`store.get/set`，键名自动加前缀 `wishpond.`。现有键：`count`、`hits`、`wishes`。
- **声音**：目前没有任何声音。不要私自加音效，声音统一走 F6。
- **文案**：界面文字用中文，代码和注释用英文。
- **预览**：直接用浏览器打开 `index.html`。也会发布为 Claude Artifact：[许愿池](https://claude.ai/artifact/KcuPEhtfwvDUy2fGKCgbFS)。
